# Online Shoppers Purchase Intention Prediction

A machine learning project that predicts whether an online shopper will complete a purchase based on their browsing behaviour.

## Project Overview

Online stores lose potential customers every day. This project analyses visitor session data and predicts purchase intent using Logistic Regression — helping businesses identify which users are likely to buy.

## Dataset

- **Source:** Online Shoppers Purchasing Intention Dataset
- **Size:** 12,330 sessions, 18 features
- **Target:** `Revenue` (True = Purchase, False = No Purchase)

## Tech Stack

- Python
- Pandas & NumPy
- Scikit-learn
- Matplotlib & Seaborn
- Jupyter Notebook

## Project Steps

1. Data Loading & Exploration
2. Data Cleaning & Preprocessing
3. Exploratory Data Analysis (EDA)
4. Model Building — Logistic Regression
5. Model Evaluation (Accuracy, Confusion Matrix, Classification Report)
6. Prediction on new sample data

## Results

- **Model:** Logistic Regression
- **Accuracy:** ~89%

## How to Run

1. Clone this repository
2. Install dependencies: `pip install pandas numpy scikit-learn matplotlib seaborn`
3. Open `machine_learning_project__1_.ipynb` in Jupyter Notebook
4. Run all cells
